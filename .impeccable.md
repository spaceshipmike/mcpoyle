## Design Context

### Users
Solo developers managing their own MCP server configurations across multiple AI clients. Power users who work at their desk, using the app as a daily driver alongside the CLI. They understand what MCP servers are, what groups and sync mean — no hand-holding needed.

### Brand Personality
Precise, utilitarian, confident. Tool-like. Respects the user's time. No decoration for decoration's sake. The interface should feel like it was built by someone who uses it every day.

### Aesthetic Direction
- **References**: Raycast, Linear — fast, keyboard-driven, clean dark UI, information-dense but not cluttered
- **Anti-references**: Electron apps that feel like wrapped websites, anything with gradients-for-gradients-sake, over-animated dashboards
- **Theme**: Dark (developer tool used during focused work sessions)
- **Tone**: Confident restraint. Dense information presented with clear hierarchy. Every pixel earns its place.

### Design Principles
1. **Density over decoration** — Show information, not chrome. Developers want to see their configs, not artwork.
2. **Confidence through clarity** — Strong typographic hierarchy, clear status indicators, no ambiguity.
3. **Tool-speed** — The UI should feel instant. No unnecessary transitions or loading theatrics.
4. **CLI parity, not CLI mimicry** — The desktop app should feel native and visual, not like a terminal with a skin.
5. **Quiet competence** — The best tools don't announce themselves. They just work.
